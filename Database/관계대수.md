# 관계대수

## 한 줄 정의
원하는 데이터를 **어떤 순서로 구할지** 연산으로 표현하는 **절차적** 언어.

## 연산 정리
| 기호 | 이름 | 의미 | SQL 대응 |
|---|---|---|---|
| **σ** | Select | 조건에 맞는 **행** 추출 (가로로 자르기) | **WHERE** |
| **π** | Project | 원하는 **열** 추출 (세로로 자르기) | **SELECT 칼럼 목록** |
| **⋈** | Join | 공통 속성으로 두 릴레이션 합치기 | JOIN |
| **÷** | Division | B의 모든 값과 관련된 A의 튜플 | |
| ∪ ∩ − × | 합·교·차·카티션 곱 | 일반 집합 연산 | UNION 등 |

## 연산자 분류
- **순수 관계 연산자**: Select(σ), Project(π), Join(⋈), Division(÷)
- **일반 집합 연산자**: Union(∪), Intersection(∩), Difference(−), 카티션 곱(×)
- Union은 순수 관계 연산자가 **아니다**

## 예시
`SELECT 이름 FROM 학생 WHERE 학년 = 3`
- `WHERE 학년 = 3` → **σ** 학년=3 (학생)
- `SELECT 이름` → **π** 이름
- 합치면: π 이름 ( σ 학년=3 (학생) )

## ⚠️ 헷갈렸던 점
- **σ의 이름이 Select라서 SQL의 SELECT와 같다고 착각하기 쉽다.**
- σ = 조건(행) = WHERE, π = 칸(열) = SELECT 뒤 칼럼

## 관계대수 vs 관계해석
| | 관계대수 | 관계해석 |
|---|---|---|
| 성격 | **절차적** ("어떻게") | **비절차적** ("무엇을") |
| 표현 | σ, π, ⋈ 등 연산자 | ∀(모든), ∃(존재) 등 논리 기호 |

## 내 말로 설명하기
> 관계대수는 행을 고르는 σ, 열을 고르는 π, 표를 합치는 ⋈ 같은 연산
> 데이터를 구하는 순서를 표현한다. SQL의 WHERE가 σ, SELECT 칼럼이 π에 해당한다.
