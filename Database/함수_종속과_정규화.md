# 함수 종속과 정규화

## 함수 종속
**X → Y**: X 값을 알면 Y 값이 하나로 정해진다. (예: 학번 → 이름)

| 종류 | 의미 | 예시 |
|---|---|---|
| 완전 함수 종속 | 기본키 **전체**에 종속 | (학번, 과목) → 성적 |
| **부분** 함수 종속 | 기본키의 **일부**에만 종속 | (학번, 과목) 중 학번 → 학생이름 |
| **이행** 함수 종속 | A → B, B → C 이면 A → C | 학번 → 학과 → 학과장 |

## 정규화
중복을 없애 **이상 현상(삽입·삭제·갱신)**을 막기 위해 테이블을 쪼개는 과정.

| 정규형 | 조건 |
|---|---|
| 1NF | 모든 값이 **원자값** (반복 그룹 X) |
| 2NF | **부분** 함수 종속 제거 |
| 3NF | **이행** 함수 종속 제거 |
| BCNF | 모든 **결정자가 후보키** |
| 4NF | 다치 종속 제거 |
| 5NF | 조인 종속 제거 |

## 이상 현상 예시
| 종류 | 상황 |
|---|---|
| 삽입 이상 | 수강 과목이 없는 학생은 기본키(과목)가 비어 저장할 수 없음 |
| 삭제 이상 | 수강 기록을 지우다가 학생 정보까지 함께 사라짐 |
| 갱신 이상 | 이름이 여러 행에 중복 저장돼, 일부 행만 바뀌어 데이터가 어긋남 |
- 조회는 데이터를 바꾸지 않아서 "조회 이상"은 없다

## 1NF 예시
| 학번 | 과목 |
|---|---|
| 1 | 수학, 영어, 과학 ❌ |

→ 한 칸에 값 하나(원자값)만 오도록 행을 나눈다

| 학번 | 과목 |
|---|---|
| 1 | 수학 |
| 1 | 영어 |
| 1 | 과학 |

## 예시로 이해하기
수강(**학번, 과목**, 성적, 학생이름)
- 성적은 학번과 과목을 둘 다 알아야 정해짐 → 완전 종속 (OK)
- 학생이름은 학번만 알아도 정해짐 → **부분 종속** → 과목 수만큼 이름이 중복 저장됨 → 2NF에서 분리

## 내 말로 설명하기
> 정규화는 중복으로 생기는 이상 현상을 막기 위해 테이블을 나누는 과정이다.
> 2NF는 기본키 일부에만 종속되는 부분 종속을, 3NF는 간접적으로 종속되는 이행 종속을 제거한다.
