# 그리디와 완전탐색

## 한 줄 정의
- **완전탐색 (브루트포스)**: 가능한 후보를 **처음부터 끝까지 다 해 보고** 조건에 맞는 걸 찾는다
- **그리디 (탐욕법)**: 매 순간 **정한 규칙대로 지금 가장 좋아 보이는 것**을 바로 고르고, 되돌아보지 않는다

## 비교
| | 완전탐색 | 그리디 |
|---|---|---|
| 방식 | 모든 후보를 전부 확인 | 규칙 하나로 바로 선택 |
| 정답 보장 | **항상 정답** | 규칙이 항상 최선일 때만 정답 |
| 속도 | 후보가 많으면 느림 | 빠름 |
| 핵심 질문 | "다 해 봐도 시간 안에 끝날까?" | "이 규칙이 항상 최선일까?" |

## 완전탐색
### 언제 쓸까
후보를 다 확인해도 시간 안에 끝날 만큼 **후보 수가 적을 때**

### 푼 문제
- **최소직사각형**: 모든 명함을 훑으며 긴 쪽·짧은 쪽 최댓값 확인
- **모의고사**: 모든 문제를 모든 수포자 패턴과 비교 (`p[i % len(p)]`로 패턴 반복)
- **카펫**: 가능한 세로 길이 h를 3부터 전부 대입
  ```python
  for h in range(3, total + 1):
      if total % h == 0:
          w = total // h
          if w >= h and (w - 2) * (h - 2) == yellow:
              return [w, h]
  ```
- **타겟 넘버**: +/- 모든 조합(2ⁿ가지)을 DFS로 확인 → 재귀를 쓴 완전탐색

## 그리디
### 일상 예시: 거스름돈
1,260원 → 500원부터 최대한 → 100원 → 50원 → 10원
"큰 동전부터 쓴다"는 규칙 하나로 바로 정한다. 모든 조합을 따지지 않는다.

### 푼 문제
- **체육복**: 체육복이 없는 학생을 번호 순서대로 보며 **앞번호 여벌부터** 빌림
  - 앞번호 여벌은 뒷사람에게 쓸모가 없으므로 먼저 쓰는 게 이득
  - 주의: lost와 reserve에 둘 다 있는 학생은 먼저 제외 (set 차집합)
- **구명보트**: **가장 무거운 사람과 가장 가벼운 사람**을 짝지음 (투 포인터)
  - 가장 무거운 사람은 어차피 보트가 필요
  - 가장 가벼운 사람과도 못 타면 누구와도 못 탄다
  ```python
  people.sort()
  left, right, boat = 0, len(people) - 1, 0
  while left <= right:
      if people[left] + people[right] <= limit:
          left += 1          # 가벼운 사람도 같이 탐
      right -= 1             # 무거운 사람은 무조건 탐
      boat += 1
  ```

### 그리디가 틀리는 경우
규칙이 항상 최선이 아닐 수 있다. 예: 동전이 1원, 4원, 6원일 때 8원 거슬러 주기
- 그리디(큰 것부터): 6 + 1 + 1 = **3개**
- 실제 최소: 4 + 4 = **2개**
→ 이런 경우는 완전탐색이나 DP가 필요하다

## 내 말로 설명하기
> 완전탐색은 가능한 경우를 전부 시도해 항상 정답을 찾지만 후보가 많으면 느리다.
> 그리디는 매 순간 정한 규칙으로 바로 선택해 빠르지만, 그 규칙이 항상 최선인지 확인해야 한다.
