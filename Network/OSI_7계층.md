# OSI 7계층

## 한 줄 정의
네트워크 통신을 **7단계로 나눠** 각 계층이 자기 역할만 담당하게 한 표준 모델.

## 계층 정리
| 계층 | 역할 | 단위(PDU) | 장비·프로토콜 |
|---|---|---|---|
| 7 응용 | 사용자 서비스 | 데이터 | HTTP, FTP, SMTP, DNS |
| 6 표현 | 암호화·압축·형식 변환 | 데이터 | JPEG, SSL |
| 5 세션 | 연결 유지·동기화 | 데이터 | |
| 4 전송 | 종단 간 신뢰성, 포트 번호 | **세그먼트** | **TCP, UDP** |
| 3 네트워크 | 경로 설정(라우팅), IP 주소 | **패킷** | **라우터**, IP, ICMP |
| 2 데이터 링크 | 인접 장비 간 전달·오류 제어, MAC 주소 | **프레임** | **스위치**, 브리지 |
| 1 물리 | 0과 1 신호 전송 | **비트** | **허브**, 리피터, 케이블 |

- PDU 순서: 데이터 → 세그먼트 → 패킷 → **프레임** → 비트

## 택배로 비유하면
- 7~5: 물건을 준비하고 포장하고 대화를 시작한다
- 4 전송: 빠짐없이 순서대로 도착하게 관리한다 (TCP = 등기, UDP = 일반 우편)
- 3 네트워크: 어느 길로 보낼지 정한다 (IP 주소, 라우터)
- 2 데이터 링크: 바로 옆 장비까지 오류 없이 전달한다 (MAC 주소, 스위치)
- 1 물리: 실제 전선으로 신호를 보낸다


## 내 말로 설명하기
> OSI 7계층은 통신 과정을 7단계로 나눈 모델이다. 4계층은 TCP/UDP로 신뢰성을,
> 3계층은 IP와 라우터로 경로를, 2계층은 MAC 주소와 스위치로 인접 장비 간 전달을 담당한다.
