# IP 주소

## 한 줄 정의
인터넷에서 **각 장비를 구분하는 주소**. 네트워크 부분 + 호스트 부분으로 나뉜다.

## IPv4 vs IPv6
| | IPv4 | IPv6 |
|---|---|---|
| 길이 | **32비트** (8비트 × 4) | **128비트** (16비트 × 8) |
| 표기 | 10진수, 점(.) 구분 (192.168.0.1) | 16진수, 콜론(:) 구분 (2001:db8::1) |
| 주소 유형 | 유니캐스트, 멀티캐스트, **브로드캐스트** | 유니캐스트, 멀티캐스트, **애니캐스트** |

## ⚠️ 헷갈렸던 점
- **IPv6에는 브로드캐스트가 없다.** 네트워크 전체에 뿌리는 방식이라 비효율적이어서 뺐고, 멀티캐스트로 대신한다.
- 애니캐스트 = 같은 주소를 가진 장비 중 **가장 가까운 하나**에게 전달

## IPv4 클래스
| 클래스 | 첫 옥텟 | 기본 서브넷 |
|---|---|---|
| A | 0~127 | /8 |
| B | 128~191 | /16 |
| C | 192~223 | /24 |
| D | 224~239 | 멀티캐스트 |
| E | 240~255 | 연구용 |

- 사설 IP: 10.x.x.x / 172.16~31.x.x / 192.168.x.x

## 서브넷 호스트 수 계산
**호스트 수 = 2^(32 − 프리픽스) − 2**
- 2를 빼는 이유: 첫 주소는 **네트워크 주소**, 마지막 주소는 **브로드캐스트 주소**라 장비에 줄 수 없다
- 예: /24 → 2⁸ − 2 = 254개 / /26 → 2⁶ − 2 = 62개 / /27 → 2⁵ − 2 = **30개**

## 내 말로 설명하기
> IPv4는 32비트라 주소가 부족해 128비트 IPv6가 나왔다. 
> IPv6는 브로드캐스트 대신 애니캐스트를 쓴다. 
> 서브넷의 호스트 수는 호스트 비트로 만든 개수에서 네트워크·브로드캐스트 주소 2개를 뺀다.
