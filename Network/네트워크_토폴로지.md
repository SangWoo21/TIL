# 네트워크 토폴로지

## 한 줄 정의
컴퓨터(노드)들을 **어떤 모양으로 연결하느냐**에 따른 네트워크 구성 방식.

## 종류
| 종류 | 구조 | 장점 | 단점 |
|---|---|---|---|
| **성형 (Star)** | **중앙 장비**(허브·스위치)에 모두 연결 | 관리 쉬움, 한 노드 고장은 영향 없음 | **중앙 장비 고장 시 전체 마비** |
| **버스 (Bus)** | 케이블 하나에 줄줄이 연결 | 설치 쉽고 저렴 | 충돌 발생, 케이블 끊기면 마비 |
| **링 (Ring)** | 원형으로 연결, 한 방향 전송 | 토큰 방식이라 충돌 없음 | 한 곳 고장 시 전체 영향 |
| **트리 (Tree)** | 계층 구조 | 확장 쉬움 | 상위 노드 고장이 하위에 영향 |
| **망형 (Mesh)** | **모든 노드가 서로** 직접 연결 | **신뢰성 최고** (다른 경로로 우회) | 회선이 많아 비용 큼 |

## ⚠️ 헷갈렸던 점
- **"중앙 장비"가 나오면 성형(Star)**이다. 링형은 중앙 없이 원형으로 이어진 구조다.

## 망형 회선 수
- **전체 회선 수 = n(n − 1) / 2**
- **노드당 포트 수 = n − 1**
- 2로 나누는 이유: A-B 선과 B-A 선은 **같은 선 하나**라서
- 예: 노드 5개 → 5×4/2 = 10개 / 노드 6개 → 6×5/2 = **15개**
- 완전 그래프의 간선 수 공식과 같다

## 내 말로 설명하기
> 성형은 중앙 장비에 모두 연결해 관리가 쉽지만 중앙이 고장 나면 전체가 멈춘다.
> 망형은 모든 노드를 서로 연결해 가장 안정적이지만 회선이 n(n−1)/2개나 필요하다.
